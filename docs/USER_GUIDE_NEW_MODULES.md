# User Guide: 10 New Modules

## Overview
Ten new modules were added in Wave 1–3: **HR, Inventory, Supply Chain, Manufacturing, IoT, Reporting, Compliance, Assets, Budgeting, Project Management**. Each follows the same UI patterns (list/detail views, search, filters, pagination, CRUD actions) described in the main User Guide.

## Features & How to Use

| Module | Purpose | Key Actions |
|--------|---------|-------------|
| **HR** | Employees, leave, timesheets, reviews | Add employee, request/approve leave, log hours |
| **Inventory** | Stock, warehouses, transfers | Add product, transfer stock, adjust levels |
| **Supply Chain** | Suppliers, purchase orders, shipments | Create PO, receive goods, track shipments |
| **Manufacturing** | Production orders, BOMs, work orders | Create BOM, schedule production, record output |
| **IoT** | Device registry, telemetry, alerts | Register device, view sensor data, set thresholds |
| **Reporting** | Standard & custom reports | Build report, schedule delivery, export PDF/CSV |
| **Compliance** | Policies, audits, violations | Assign policy, log audit, track remediation |
| **Assets** | Asset registry, depreciation, maintenance | Add asset, schedule maintenance, record depreciation |
| **Budgeting** | Budgets, forecasts, variance | Create budget, compare actuals, adjust forecast |
| **Project Management** | Projects, Gantt, milestones, budget | Create project, assign team, track milestones |

## Common Workflows
- **Create record:** Click **+ New** (top-right) → fill form → **Save**.
- **Search/Filter:** Use search bar or filter panel above any list.
- **Edit/Delete:** Open record → **Edit** or **Delete** (trash icon).
- **Pagination:** Navigate pages via controls below list.
